# Changelog

## 1.0.0

- Added local-first Nostr personas, ownerless `/h/` communities, multi-topic posts, editable posts/comments, nested discussion, follows, blocks, norms, votes, reaffirmations, emoji, feeds, search, Revisit, media, encrypted backup, and persona messaging.
- Added Open Nostr discovery with explicit Uncategorized notes, private local categorization, and standard repost curation into `/h/` topics.
- Added the optional Reddit Bridge with OAuth, transient live browsing, opt-in post/comment projection, edit synchronization, and divergence handling.
- Deferred Reddit vote projection pending policy clarification while retaining Nostr votes and reaffirmations.
- Added selective import of the user’s posts and comments from Reddit’s official account-data export, including an in-app imported-writing library and exact source permalinks.
- Added Big Stick and terminal Reddacted for Hydra-originated Reddit projections.
- Added a narrow Firefox companion without access to Nostr keys.
- Added Rust, JavaScript, protocol, runtime, extension, packaging, and installed-app release gates.
